# Volunned.in

**Volunned.in** is a volunteer management platform designed to connect individuals with opportunities to serve the community through verified NGOs and social organizations. The goal is to make volunteering simpler, trackable, and more impactful.

## 🎯 Key Features

- 🙋 Volunteer Sign-Up and Login
- 🏢 NGO Registration and Verification
- 📅 Events Listing and Participation
- 📝 Volunteer Work Logs and Certificates
- 🗃️ Admin Dashboard to Manage Events, NGOs, and Users
- 📊 Impact Tracking for Users (Hours Contributed, Events Attended)
